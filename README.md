# LocaTues

A free, open-source, offline-first Android music player for audio files stored on your device.

## Current MVP
- Browse music indexed by Android MediaStore.
- Play local audio with AndroidX Media3 / ExoPlayer.
- Play, pause and skip to the next track.
- Dark interface.
- No account, analytics, ads, or internet permission.

## Build
1. Open this repository in Android Studio (JDK 17).
2. Install Android SDK 35 and let Gradle sync.
3. Run on an Android device (API 23+) or emulator.
4. Grant the audio permission when prompted.

## Roadmap
Background playback and media notification, seek bar, album artwork, search, playlists, shuffle and repeat.
